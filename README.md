# 🎮 Xbox Game Pass — Dashboard de Vendas no Excel

## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **dashboard de vendas no Microsoft Excel**, com foco na organização, análise e visualização de dados relacionados às assinaturas do Xbox Game Pass.

O objetivo foi transformar uma base de dados em informações relevantes para a análise de vendas, utilizando cálculos, tabelas dinâmicas e recursos visuais para facilitar a interpretação dos resultados e apoiar a tomada de decisões.

## 🎯 Objetivos

- Organizar e estruturar a base de dados para facilitar as análises.
- Calcular o faturamento das assinaturas de acordo com diferentes critérios.
- Analisar as vendas por tipo de plano e modalidade de assinatura.
- Desenvolver visualizações que facilitem a compreensão dos resultados.
- Aplicar técnicas de formatação e elementos visuais para melhorar a apresentação do dashboard.

## 🛠️ Ferramentas e Recursos Utilizados

- **Microsoft Excel:** desenvolvimento da solução e construção do dashboard.
- **Tabelas Dinâmicas:** consolidação e análise dos dados por categorias.
- **Fórmulas e cálculos:** apuração de valores e respostas a perguntas de negócio.
- **Formatação de dados:** padronização e organização das informações.
- **Assets visuais:** utilização de elementos gráficos para compor a identidade visual do dashboard.

## 📊 Análises Realizadas

O projeto foi estruturado para responder a perguntas relevantes sobre o desempenho das vendas:

- Qual é o faturamento total das assinaturas anuais?
- Como o faturamento das assinaturas anuais se distribui entre renovações automáticas e não renovações?
- Qual é o valor total das vendas de assinaturas do EA Play?
- Qual é o valor total das vendas de assinaturas do Minecraft Season Pass?

As análises utilizam tabelas dinâmicas e cálculos no Excel para consolidar os dados e apresentar os resultados de forma organizada.

## ⚙️ Desenvolvimento

O desenvolvimento foi dividido em quatro etapas principais:

1. **Organização da base de dados:** estruturação das informações para permitir consultas e análises.
2. **Construção dos cálculos:** utilização de recursos do Excel para responder às perguntas de negócio.
3. **Criação das tabelas dinâmicas:** consolidação dos dados por categorias e critérios de análise.
4. **Desenvolvimento do dashboard:** aplicação de formatação, organização visual e assets para apresentar as informações de maneira intuitiva.

## 💡 Principais Aprendizados

- Organização e análise de bases de dados no Excel.
- Utilização de tabelas dinâmicas para resumir informações.
- Aplicação de cálculos para responder a perguntas de negócio.
- Transformação de dados em informações visuais para facilitar a interpretação.
- Desenvolvimento de dashboards com foco em clareza, organização e apresentação dos resultados.

## 🚀 Conclusão

Este projeto representa uma oportunidade de colocar em prática conhecimentos de Excel e análise de dados, explorando recursos que permitem transformar informações brutas em análises estruturadas e visualmente acessíveis.

Além do desenvolvimento técnico, o projeto reforça a importância de compreender as necessidades do negócio e utilizar os dados para responder a perguntas relevantes.
